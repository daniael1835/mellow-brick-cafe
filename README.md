# 말랑말랑 브릭 카페 ✿

A cozy, pastel brick-breaker built with vanilla HTML, CSS and Canvas. No build or dependencies required.

Play with mouse, touch, or Left/Right (A/D). Click or press Space to launch; P/Escape pauses. Five stages, combo scoring, three lives, optional synthesized audio and local high scores.

Open `index.html` directly, or serve this folder with any static web server. GitHub Pages serves the main branch root.

Fonts are optionally loaded from Google Fonts, with system font fallbacks. No analytics, accounts, or backend. High scores stay on your device.
